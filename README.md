# 💫 About Me:
Hi, I'm Ahmad Abdulnasir Shuaib. I'm a Web Developer and Machine Learning Engineer based in Kano, Nigeria. I currently work as an AI Software Engineer at eHealth Africa Foundation, where I focus on designing and deploying production-ready AI applications.<br>I have over 7 years of experience in software development, with expertise in both frontend and backend technologies like Python, Django, ReactJS, and various machine learning frameworks including TensorFlow and PyTorch. I've worked across different industries - from healthcare and energy to retail - building everything from data warehouses and APIs to computer vision solutions like shoplifting detection systems.
